# Descripción general

Guardian Misti es una experiencia breve en primera persona que presenta una simulación de respuesta ante un sismo y evacuación posterior. El jugador practica identificar protección bajo una mesa, reunir suministros, activar elementos de emergencia y llegar a una zona segura exterior durante una réplica simulada.

Se orienta a comunicar conductas básicas: mantener la calma, alejarse de elementos inestables, agacharse y cubrirse, esperar el fin del movimiento principal y continuar una ruta señalizada. No se encontró una edad objetivo exacta; puede describirse prudentemente como material demostrativo para estudiantes o público general.

El menú inicia Level01: preparación, sismo, protección, salida, mochila y activación. Level02 introduce radio, llave, baliza, réplica, riesgos exteriores y tienda médica. El final muestra misión completada.

Incluye locomoción FPS, cámara, salto, agachado, interacción, inventario, objetivos, sismo, réplica, señales, iluminación, métricas y resultado. Excluye simulación científica, entrenamiento certificado, multijugador, móvil, campaña extensa y validación educativa formal.
